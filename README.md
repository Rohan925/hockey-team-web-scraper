# 🏒 Hockey Team Web Scraper

A Python web scraping project that collects hockey team statistics from multiple pages of **Scrape This Site** and stores the extracted data in a CSV file.

## 📌 Features

* Scrapes data from 24 pages
* Extracts hockey team statistics
* Uses BeautifulSoup for HTML parsing
* Uses Requests to send HTTP requests
* Stores the collected data in CSV format
* Handles multiple pages automatically

## 📊 Data Collected

* Team Name
* Year
* Wins
* Losses
* OT Losses
* Win Percentage
* Goals For
* Goals Against
* Goal Difference

## 🛠️ Technologies Used

* Python
* Requests
* BeautifulSoup
* CSV

## 🎯 Project Purpose

This project was created to practice **Python web scraping, HTML parsing, pagination, data extraction, and CSV data handling**.

The project can be further extended to clean the data, analyze team performance, and visualize the results using Pandas and Matplotlib.
